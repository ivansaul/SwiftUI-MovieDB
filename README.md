<h1 style="border-bottom: none">
    <b><a href="#">SwiftUI MovieDB App</a></b>
</h1>

A complete `MovieDB` app built with `SwiftUI`.

The app allows users to explore movies, view details, and manage favorites, using the latest Swift technologies for a smooth and modern experience.

This project follows **`Model View ViewModel (MVVM)`** architecture principles for a modular and maintainable codebase. It uses **`SwiftData`** for data persistence, **`The Movie Database (TMDB)`** API for fetching movie data, **`Apple Async Algorithms Package`** for reactive programming, and **`async/await`** for asynchronous operations.

🚧 This project is still under active development.
